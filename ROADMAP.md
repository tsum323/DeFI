**Известные ограничения:**
- Лимит Alchemy на текущий месяц исчерпан; дальнейшая работа — через бесплатный dRPC
  (`python -m scripts.sync_pool --endpoint drpc`). Загрузчик больше не запрашивает заголовок
  каждого блока: время — из `blockTimestamp` логов, base fee — `eth_feeHistory` (1024 блока/запрос),
  один контрольный заголовок на окно.
- База `data/lab.sqlite` (~1 ГБ) живёт только в контейнере; после новой сессии —
  `data_snapshot restore`, затем `sync_pool --endpoint drpc` догружает свежие блоки.
  Снимок обновлять командой `python -m scripts.data_snapshot export` (перезаписывает части).
- PublicNode бесплатно — не архив (только ~2–3 дня), `sync_pool` его не использует.
- Газ: средние величины; реальный газ mint выше, если тики позиции ещё не инициализированы
  (p90 ≈ 488k). Цена газа — base fee блока + приоритет `priority_fee_gwei` (предположение).
- Распределение ликвидности, tick crossings и fee growth не хранятся отдельно — они строятся
  replay'ем событий в этапах 3–4 (DATA_SOURCES §1).

## Этап 4 — Backtesting Engine ✅
- ✅ `pool_replay.py` — точное восстановление состояния пула из событий: TickBitmap (шаги свопа
  останавливаются на тех же границах слов, что on-chain), пересечения тиков, Mint/Burn/Collect с
  учётом всех реальных позиций, Flash, протокольная комиссия. Каждый Swap воспроизводится в том
  режиме (exact-in / exact-out / по цене), который даёт событие побитово; иначе — остановка.
  Вся история (717 865 событий) — ~18 с, 0 расхождений
- ✅ Контрольные точки (`verify_replay_checkpoints`): `slot0`, `liquidity`, `feeGrowthGlobal0/1`,
  `protocolFees`, `ticks(i)`, `positions(key)` против `eth_call` в 8 блоках 2022–2026 —
  **175 / 175 побитово**
- ✅ `fee_meter.py` — комиссии диапазона на реальном пути цены, две границы: A (фиксированный
  объём, консервативная) и B (фиксированный путь, оптимистичная). Проверка на 400 реальных
  позициях (`validate_fee_meter`): модель B = feeGrowthInside контракта **400 / 400 точно**
- ✅ `position_sim.py` — `simulate(dataset, spec)`: открытие, swap под соотношение диапазона через
  реальное состояние пула (комиссия + price impact), mint/burn с округлениями контракта,
  перестановка при выходе из диапазона (с задержкой), газ = калиброванные единицы ×
  (baseFee блока решения + priority) × ETH/USD (Chainlink), IL реализованный/нереализованный,
  HODL, net A/B, APR, просадка, time-in-range, флаг `SIZE_IMPACT` (L_p/L > 1%).
  Решение по данным ≤ b, исполнение на состоянии начала b+1 — без look-ahead (тест)
- ✅ ETH/USD: `fetch_eth_usd` — 2 007 дневных значений Chainlink ETH/USD (адрес проверен по
  `description() == "ETH / USD"`)
- ✅ CLI `python -m scripts.backtest --from … --to … --width … --rebalance on_exit`
- ✅ Тесты (`tests/test_backtest.py`, SYNTHETIC): тождества учёта, B = доля L_p/L комиссий,
  отсутствие комиссий вне диапазона, перестановки, no look-ahead, запрет старта до London

Пример (WBTC/USDC 0.3%, 2025-01-01 → 2026-11-01, $10 000, MODELED):

| стратегия | комиссии A | газ | перестановок | net A | против HODL |
|---|---|---|---|---|---|
| ±10%, перестановка при выходе | $6 467 | $1 151 | 37 | −$1 333 | −$489 |
| ±50%, без перестановок | $2 398 | $10 | 0 | +$1 314 | +$2 176 |

**Известные ограничения:**
- Собранные комиссии не реинвестируются (держатся отдельно) — так пути A и B совпадают.
- USDC считается равным $1 (депег марта 2023 не моделируется).
- Позиция оценивается по рынку на конец периода, газ закрытия не вычитается.
- Газ — по baseFee блока решения (базовая цена следующего блока близка, но не хранится).
- Гипотетический swap/mint не меняет исторический путь цены (MODELED; при L_p/L > 1% — `SIZE_IMPACT`).
- Выход из диапазона проверяется на конец блоков с событиями пула.
- Старт бэктеста — не раньше London (блок 12965000): до него нет baseFee.
