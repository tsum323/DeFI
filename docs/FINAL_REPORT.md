## Автоматический режим (SPEC §16)

Планировщик `python -m scripts.scheduler run` (или `once` из cron): загрузка данных → проверка источников → анализ рынка и сигналы → виртуальные позиции и прямые тесты → проверка устойчивости и оптимизация (тяжёлые, не параллельно) → гипотезы (при ключе API) → отчёт → сохранение архива. Журнал — таблица `job_runs` (`scheduler log`), пауза/возобновление/ручной запуск — `pause` / `resume` / `run-now`.

**Ограничения:** система обновляется только пока запущена — для круглосуточной работы её нужно развернуть на постоянно работающем компьютере/сервере; один пул; комиссии гипотетической позиции — модельные (A/B); OOS-отрезки многократно использованы для отбора — окончательная проверка только на новых данных (прямые тесты).
