# Риски и технические ограничения

## Данные
| Риск | Влияние | Мера |
|---|---|---|
| **RPC/индексаторы заблокированы в текущем окружении** | реальные данные не загружаются — блокирует этапы 2+ в части реальных прогонов | разрешить archive-RPC домен в настройках сети окружения, `ETH_RPC_URL` (DATA_SOURCES §2) |
| Лимиты `eth_getLogs` у публичных RPC | медленный бэкфилл, обрывы | адаптивные окна, ретраи, `sync_gaps`, BigQuery для бэкфилла |
| Нет archive-узла | нет побитовых контрольных точек состояния | опора на инварианты Swap-событий; помечать отчёт «без checkpoint» |
| Реорги | дубли/пропуски | 64 подтверждения, проверка `blockHash` |
| Пропущенное окно логов | неверная ликвидность тиков ⇒ неверные комиссии навсегда после этого места | непрерывность покрытия + инварианты replay останавливают симуляцию |

## Модель
| Ограничение | Последствие | Как обозначено |
|---|---|---|
| Гипотетическая позиция меняет путь цены | комиссии не точны | две границы A/B, метка `MODELED`, флаг `SIZE_IMPACT` при `L_p/L > 1%` |
| JIT-ликвидность и MEV | реальные LP теряют часть комиссий крупных свопов JIT-провайдерам; в реплее это уже учтено (JIT Mint/Burn в событиях), но наша позиция не может «конкурировать» | документируется; метрика доли JIT в объёме |
| LVR / токсичный поток (арбитраж против CEX) | основная причина убытков LP; вписан в IL | показываем IL и «vs HODL» отдельно |
| Газ — ассумпции до калибровки | искажение результата частых перестановок | калибровка по реальным receipts NPM; тест чувствительности ×0.5/×2 |
| Проскальзывание ребаланс-свопа | считается только через этот пул | ограничение указано; агрегаторы не моделируются |
| Протокольная комиссия (fee switch) | при включении LP получают меньше | обязательная обработка `SetFeeProtocol` |
| Исполнение не в блоке решения | реальная задержка | `execution_delay_blocks`, чувствительность |
| Переобучение на истории | ложные «прибыльные» стратегии | OOS, walk-forward, штраф за чувствительность, Robustness-оценка |
| Смена режимов рынка | прошлое ≠ будущее | сигналы — диапазоны сценариев, фильтры, срок актуальности |

## Активы
- **WBTC ≠ BTC.** Кастодиальная обёртка (смена кастодиальной схемы в 2024 г.).
  Риск депега/заморозки не моделируется ценой пула заранее; указывается в каждом сигнале.
- **USDC = $1 — допущение.** Прецедент депега (март 2023). В отчётах помечается.
- Смарт-контрактный риск Uniswap v3 не входит в модель.

## Безопасность и правовое
- Проект не может отправлять транзакции (allowlist + отсутствие ключей + тесты).
- Сигналы — исследовательский результат, не инвестиционная рекомендация.
- Ключ Claude API хранится только в переменной окружения.
